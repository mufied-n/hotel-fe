06 / Motion rules

Tenang dan konsisten.

Section: 280ms / 10px
Route: 180ms / 6px
Result: 180ms / fade
Hover: 140ms / 2px
Press: 90ms / .98

Reduced motion: state langsung, tanpa translate, scale, spinner berputar atau shimmer. Header, sticky actions, input, harga, consent, deadline dan tabel operasional tidak mengikuti scroll reveal.

Foto siap dan dialog exit memerlukan pemeriksaan lifecycle pada implementasi. Storyboard ini memperagakan inti motion; bukti aplikasi berada pada laporan QA.
